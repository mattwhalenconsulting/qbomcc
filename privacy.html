Privacy Policy

Personal QuickBooks Assistant, a private application for personal use.

Who this applies to

This application is used only by its owner, to access the owner's own QuickBooks Online company. It is not available to any other person or organization, and it does not collect information from any other individual.

What data is accessed

With the owner's authorization through Intuit's OAuth process, the application reads accounting data from the owner's own QuickBooks Online company, such as reports, accounts, customers, vendors and transactions. In its current configuration it is restricted to read-only use.

How data is used

Data retrieved from QuickBooks is shown to, and processed by, the AI assistant the owner uses on the owner's own computer, in order to answer the owner's questions about the owner's own finances. The data is used for no other purpose.

Storage and security

OAuth credentials and tokens are stored in a file on the owner's own computer, outside any shared or public location. No QuickBooks data is stored on a server operated by this application.

Sharing

The application does not sell, rent or share QuickBooks data with any third party, and does not use it for advertising.

Retention and deletion

The owner can revoke the application's access at any time from the Intuit account (see Disconnecting the app) and can delete the locally stored credentials file at any time.

Changes

This policy may be updated from time to time. The current version is always published at this address.

Contact

Questions about this policy can be raised by opening an issue on the repository that hosts this page.
